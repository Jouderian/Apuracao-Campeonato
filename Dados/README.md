# Dados das Competições por Ano

Cada subpasta `<ano>/` armazena:
- `entradas/`: extrações higienizadas das etapas (sem dados pessoais sensíveis) e relação oficial de voluntários/árbitros.
- `resultados/`: relatórios de classificação individual e por clubes gerados pelo motor de cálculo.

Os hashes SHA-256 dos bancos `.mdb`/`.accdb` originais ficam registrados em [`arquivosCongelados.sha256`](arquivosCongelados.sha256).
